# ShotCat 截图上镜猫

> 截图太素？让猫给它化个妆。

喵造实验室 012，一个本地优先的 Windows 截图美化工具。

## v0.1

- PNG / JPG / WEBP
- 小红书 3:4、1:1、16:9、9:16、README 预设
- Mint / Dark / Sunset / Lavender / Cream / Minimal 六套模板
- 主标题 / 副标题
- 模拟窗口标题栏
- 留白、圆角、阴影、缩放
- 一键导出 PNG
- 全程本地处理，截图不上传
- 原图不修改

## 开发

```bash
npm install
npm test
npm run check
npm start
```

Windows 打包：

```bash
npm run dist:win
```

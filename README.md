# ShotCat 截图上镜猫

> 截图太素？让猫给它化个妆。

喵造实验室 012，一个本地优先的 Windows 截图美化与宣传图制作工具。

## v0.2

### 新增：宣传图模式

把一张普通软件截图快速变成可以直接发布的宣传图：

- 产品名
- 顶部角标
- 大标题
- 副标题
- 3 个卖点标签
- 右上版本徽章
- 喵造实验室品牌角标
- 软件截图卡片
- 自动适配竖版 / 横版画布

特别适合：

- 小红书软件首发
- 软件更新图
- GitHub README
- 产品介绍图
- 社交媒体宣传图

### 保留：自由美化模式

- PNG / JPG / WEBP
- 小红书 3:4、1:1、16:9、9:16、README 预设
- Mint / Dark / Sunset / Lavender / Cream / Minimal 六套模板
- 自定义主标题 / 副标题
- 模拟窗口标题栏
- 留白、圆角、阴影、截图缩放
- 一键导出 PNG

## 隐私

截图全程在本机处理：

- 不上传截图
- 不修改原图
- 导出使用完整目标像素

## 开发

```bash
npm install
npm test
npm run check
npm start
```

Windows 打包：

```bash
npm run dist:win
```

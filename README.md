# ShotCat 截图上镜猫

> 截图太素？让猫给它化个妆。

喵造实验室 012，一个本地优先的 Windows 截图美化与宣传图制作工具。

## v0.3

### 新增：海报模板库

一键套用 5 套常用发布模板：

- 软件首发
- 功能更新
- Before & After
- 免费工具
- GitHub 开源

每个模板会自动配置：

- 推荐画布尺寸
- 推荐视觉主题
- 顶部角标
- 产品名
- 主标题 / 副标题
- 3 个卖点标签
- 版本徽章

### 真正的 Before & After

v0.3 支持第二张截图：

- 第一张：Before
- 第二张：After
- 自动双栏排版
- 适合界面改版、截图美化、设计优化、版本升级
- 第二张截图仍然只在本机读取，不上传

### 保留：宣传图模式

- 大标题 / 副标题
- 卖点标签
- 品牌角标
- 软件截图卡片
- 自动适配横版 / 竖版
- 一键导出完整像素 PNG

### 保留：自由美化模式

- PNG / JPG / WEBP
- 小红书 3:4、1:1、16:9、9:16、README
- Mint / Dark / Sunset / Lavender / Cream / Minimal
- 留白、圆角、阴影、缩放
- 模拟窗口标题栏

## 隐私

截图全程本地处理：

- 不上传截图
- 不修改原图
- 不需要登录
- 导出使用完整目标像素

## 开发

```bash
npm install
npm test
npm run check
npm start
```

Windows 打包：

```bash
npm run dist:win
```

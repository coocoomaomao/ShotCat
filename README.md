# ShotCat 截图上镜猫

> 截图太素？让猫给它化个妆。

喵造实验室 012，一个本地优先的 Windows 截图美化与宣传图制作工具。

## v0.4

### 新增：自己的模板

把当前调好的样式保存成「我的模板」，下一次直接一键复用。

会保存：

- 制作模式（宣传图 / 自由美化）
- 画布尺寸与视觉主题
- 宣传文案 / 自由标题
- 卖点标签与版本徽章
- 品牌角标开关
- 窗口框、留白、圆角、阴影、截图缩放
- Before & After 的版式选择

不会保存：

- 原始截图
- 第二张对比截图
- 任何上传到网络的内容

模板保存在本机，支持最多 20 个，可一键套用、覆盖、改名和删除。

## v0.3

### 海报模板库

一键套用 5 套常用发布模板：软件首发、功能更新、Before & After、免费工具、GitHub 开源。

### Before & After

支持第二张截图，自动双栏排版，适合界面改版、截图美化、设计优化和版本升级。

## 主要功能

- 宣传图模式：大标题、副标题、卖点标签、品牌角标、自动横竖版构图
- 自由美化模式：背景、留白、圆角、阴影、缩放、窗口标题栏
- PNG / JPG / WEBP 导入
- 小红书 3:4、1:1、16:9、9:16、GitHub README 尺寸
- Mint / Dark / Sunset / Lavender / Cream / Minimal
- 一键导出完整像素 PNG

## 隐私

截图全程本地处理：

- 不上传截图
- 不修改原图
- 不需要登录
- 自定义模板也只保存在本机
- 导出使用完整目标像素

## 开发

```bash
npm install

npm run check

```

Windows 打包：

